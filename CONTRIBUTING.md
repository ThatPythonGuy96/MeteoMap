# Contributing to MeteoGIS

Thank you for your interest in contributing to MeteoGIS! Contributions that improve GIS visualization, climate analysis, data processing, documentation, and application usability are welcome.

## How to Contribute

1. **Fork** the repository.
2. **Clone** your fork locally.
3. Create a branch for your changes.
4. Install the project dependencies.
5. Make your changes and test them.
6. Commit your changes with a clear commit message.
7. Push your branch and open a Pull Request.

## Development Setup

Ensure you have a compatible Python version installed.

```bash
git clone https://github.com/ThatPythonGuy96/MeteoGIS.git
cd MeteoGIS

python -m venv .venv
```

Activate the virtual environment, then install the dependencies:

```bash
python -m pip install -r requirements.txt
```

## Contribution Guidelines

- Keep code readable and maintainable.
- Follow existing project conventions.
- Test changes before submitting a Pull Request.
- Update documentation when necessary.
- Do not commit credentials, private datasets, virtual environments, or generated files.
- Explain the purpose of your changes in your Pull Request.

## Reporting Bugs

When reporting a bug, include steps to reproduce it, the expected behavior, the actual behavior, and relevant error messages.

## Feature Requests

Describe the proposed feature, its intended use, and how it would benefit MeteoGIS users.

Thank you for helping improve MeteoGIS!
